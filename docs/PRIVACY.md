# 隐私说明

## 本机边界

本软件只读取运行它的 Windows 用户目录。默认服务绑定：

```text
127.0.0.1
```

它不登录云端账号，不上传统计，不调用模型接口，也不把会话正文发送到外部服务。

## 只读来源

源 SQLite 数据库使用只读 URI 打开；JSON、JSONL 和导出文件按只读方式解析。程序不会写入、重命名、删除或迁移其他软件的数据。

程序自己的运行数据写入：

```text
%LOCALAPPDATA%\AgentTokenLedger
```

包括运行日志和 WebView 临时配置。运行日志按大小自动轮转，也可以在“设置 → 运行控制 → 清除历史缓存”里清除浏览器临时文件与运行日志。删除或清理这个目录只会影响本软件自己的运行缓存，不会删除来源日志。

## 开机自动启动

“设置 → 运行控制 → 开机自动启动”默认关闭。只有用户主动开启后，程序才会在当前 Windows 用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中写入一个名为 `AgentTokenLedger` 的启动项；关闭开关时只删除这一个值。源码运行不会修改系统启动项。

## 报告隐私

文本、JSON 和 CSV 报告包含本机来源目录、扫描时间和统计结果。它们适合本地检查和交付，但不应直接提交到公开 GitHub 仓库。

公共源码包不包含：

- `var\ledger.sqlite`
- 本机扫描报告
- WebView 用户缓存
- 其他智能体的原始日志或数据库

只发布 `-source.zip`；`-reports.zip` 和 `-delivery.zip` 留在本机。
